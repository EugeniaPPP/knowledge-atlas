# Knowledge Atlas

Интерактивный учебник по Yale ECON 159: Game Theory. Русский и английский тексты, режимы Quick / Core / Mastery, локальные ответы и прогресс. Статическое приложение на Astro, MDX и React.

## Разработка

Node.js 24; npm и `package-lock.json`.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm test
npm run build
npm run test:dist
npm run test:e2e
```

Браузеры Playwright устанавливаются отдельно: `npm exec playwright install`. На macOS тесты Chromium автоматически используют установленный Google Chrome, если он доступен. Функциональные сценарии выполняются также в Firefox и WebKit; визуальные эталоны фиксируются в Chromium и принимаются после просмотра.

Для локального просмотра собранной версии: `npm run build`, затем `npm run preview`. Остановка фонового preview-сервера Astro: `npm exec astro preview stop`.

Локальный сайт открывается с префиксом **http://127.0.0.1:4321/knowledge-atlas/**. Тот же префикс используется при разработке, preview и публикации.

Если порт 4321 уже занят сервером разработки, запусти preview на другом порту (`npm run preview -- --port 4322`) и проверки через `PLAYWRIGHT_PORT=4322 npm run test:e2e`.

После изменения схемы коллекций давно работающему dev-серверу может потребоваться перезапуск: `npm exec astro dev stop`, затем `npm run dev -- --background --port 4321`. Это сбрасывает серверный кеш схемы, а не браузерные данные.

## GitHub Pages

Автоматическая публикация при push в `main` настроена на **https://eugeniappp.github.io/knowledge-atlas/**. Настройка GitHub и локальная проверка описаны в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Commit и push выполняются после явного подтверждения пользователя.

## Правила

- `AGENTS.md` — работа с репозиторием и границы изменений.
- `DESIGN.md` — утверждённая система Modern Editorial.
- `CONTENT_GUIDELINES.md` — редакционные и учебные принципы.
- `docs/TERMINOLOGY.md` — английские термины Yale и их русские соответствия.
- `docs/CONTENT_SCHEMA.md` — формат контента, источники и контракт авторского пакета.
- `references/` — исходные референсы, сохраняются без изменений.

Первая глава доступна на русском и английском; русская вторая глава опубликована, полная английская редакция подготовлена локально. Обе RU/EN главы приняты как авторские эталоны; это не отдельная команда на публикацию. Обе главы включают Quick, Core и Mastery. Проектный skill `author-lesson` готовит новые главы с редакционными остановками; автоматический публикационный pipeline не создан. Пользовательские данные не отправляются во внешние сервисы.

## Подготовка новых глав

Источники: `authoring/sources/<course>/<lesson>/raw/` (локально/gitignored). В чате этого проекта: `$author-lesson Подготовь Blueprint для yale-econ-159/lecture-03; источники: authoring/sources/yale-econ-159/lecture-03/raw/; остановись до Core`. Этапы: Blueprint → Core RU → Quick/Mastery RU → English adaptation → bilingual QA → integration package, с отдельными согласованиями. [Подробная инструкция](docs/AUTHOR_LESSON.md), [пробный запуск](docs/AUTHOR_LESSON_DRY_RUN.md).

## Два языка

Первая глава полностью доступна на русском и английском: Quick, Core, Mastery, пояснения, упражнения, источники и словарь понятий. Переключатель в шапке сохраняет режим и текущий раздел; состояние обучения и заметки общие. Язык указан в URL и сохраняется при обновлении страницы. Русские адреса прежние, английские начинаются с `/en/` после префикса сайта.

- RU Core: `http://127.0.0.1:4321/knowledge-atlas/courses/yale-econ-159/lecture-01/core/`
- EN Core: `http://127.0.0.1:4321/knowledge-atlas/en/courses/yale-econ-159/lecture-01/core/`

Лекция 2 опубликована сначала на русском; полная английская редакция доступна локально и принята вместе с RU как эталон. `availableLocales: ["ru", "en"]` включает реальные маршруты обоих языков в текущей сборке, но не означает разрешение на deploy. Следующие лекции готовим сразу в двух языках, последовательно согласуя RU, затем EN. Схема файлов и контракт `author-lesson` описаны в `docs/CONTENT_SCHEMA.md`, редакционная проверка — в `CONTENT_GUIDELINES.md`. Исходный русский Core сохранён.

## Тема оформления

При первом открытии оформление следует системной настройке. Кнопка в шапке переключает светлую и тёмную тему (Графит) одним нажатием: луна включает тёмную, солнце — светлую. Ручной выбор сохраняется в этом браузере и действует на всех страницах и обоих языках. Он хранится отдельно от прогресса главы; импорт, экспорт и сброс учебных данных его не меняют. Без JavaScript оформление следует системной теме, текст остаётся доступен целиком.

## Лекция 2

Локально: `/knowledge-atlas/courses/yale-econ-159/lecture-02/{quick,core,mastery}/`. Восемь шагов, семь составных заданий и необязательное объяснение. Исходное число из главы 1 сохраняется отдельным снимком; текущее и повторное можно менять. Исходные файлы Yale и внутренний handoff остаются локальными/gitignored.

Контракты компонентов: `docs/COMPONENT_CATALOG.md`. Проверки интеграции и ограничения: `docs/LECTURE_02_QA.md`. Публикация требует отдельного разрешения.

Английская лекция 2: `/knowledge-atlas/en/courses/yale-econ-159/lecture-02/{quick,core,mastery}/`. Терминология сверена с исходным транскриптом и blackboard notes; отчёт и границы проверки — `docs/LECTURE_02_EN_REVIEW.md`. Изменение языка сохраняет исходный прогноз, ответы, заметки и оформление.
