# Выводы эталонных Лекций 1–2

Рабочее дополнение к [редакционным правилам](CONTENT_GUIDELINES.md). Основано на `references/handoff-lecture-02/docs/CONTENT_AUTHORING_ADDENDUM.md` и фактических RU/EN версиях; исторический оригинал остаётся неизменным.

- Общее у эталонов — три режима, связное объяснение, явные модели/предпосылки, самостоятельный Mastery. Совпавшие числа шагов/упражнений не становятся шаблоном.
- Существенная оговорка находится в основном тексте. В Лекции 2 это особенно важно для последовательного исключения **слабо** доминируемых стратегий и условий о поведении/знаниях других.
- Лучший ответ, парное доминирование и глобально доминирующая стратегия различаются и в тексте, и в расчётах, и в UI. «Никогда не лучший ответ» не доказывает доминирование другой чистой стратегией.
- Новая задача требует независимого решения, проверки неверных вариантов и границ. Ошибка 23 вместо 22 была обнаружена в конкретной Mastery-задаче ½ среднего, 100 игроков, диапазон 1–90. Её ответ нельзя механически переносить на другую игру.
- Исторические экспериментальные числа не являются универсальной закономерностью. Исторические участники, авторская адаптация и внешний современный пример обозначаются отдельно.
- Межглавное состояние проектировать явно: сохранённый прогноз, его snapshot и поздняя редакция — разные значения. Авторский процесс не читает реальные ответы учащегося и не обещает перенос между origin.
- Перевод — самостоятельная языковая реализация той же логики: сохраняются числа, обозначения, роли, assumptions, objectives, keys и источники. Смысловую полноту нельзя заменить совпадением ID.
- Не прятать необходимые для решения данные в другом режиме; не превращать исследовательский выбор в автоматически оценённый ответ. Проверка — явное действие, неверный ответ не запрещает читать разбор.

## Рубрика для редакционного просмотра

0 — отсутствует, 1 — частично, 2 — выполнено; каждый балл сопровождается наблюдаемым основанием.

| Критерий | Проверка |
| --- | --- |
| Научная точность | Определения, числа, выводы и предпосылки корректны |
| Самостоятельность | Глава понятна без видео; задача решается по своему условию |
| Связность | Каждый следующий шаг мотивирован предыдущим |
| Язык RU/EN | Обе версии читаются естественно как учебник |
| Optional depth | Без раскрытий не теряется обязательное объяснение |
| Интерактивность | Действие помогает понять предмет, нет quiz-gates |
| Mastery | Есть уместный перенос, независимые ключи и разбор |
| Прослеживаемость | Существенные утверждения и модели имеют проверяемые источники |
| Двуязычная полнота | Сохранены содержание, условия, обозначения и все пояснения |

Для предъявления на финальную приёмку — без нулей; точность, самостоятельность, прослеживаемость и двуязычная полнота должны получить 2. Это рабочая редакционная рубрика, не научная метрика. Существенное фактическое/математическое расхождение блокирует готовность независимо от суммы; баллы и тесты не одобряют пакет автоматически.
