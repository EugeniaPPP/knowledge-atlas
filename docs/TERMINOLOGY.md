- Модель только собственной оценки: `(0,0), (3,−1); (−1,3), (1,1)`.
- Оба учитывают справедливость: `(0,0), (−1,−3); (−3,−1), (1,1)`.
- Ты учитываешь справедливость, партнёр — только свою оценку: `(0,0), (−1,−1); (−3,3), (1,1)`. У партнёра α строго доминирует β; твоя α — лучший ответ на его α, но не доминирующая стратегия.
