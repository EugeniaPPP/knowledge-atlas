# Терминология RU / EN — Yale ECON 159

Словарь версии 1: `src/content/terminology/game-theory.json`. Английские термины восстановлены по оригиналу Yale, затем сопоставлены с русским Core 3.0. Не переводить английский через русские синонимы. Обе версии объясняют одну модель естественным языком, без буквального копирования синтаксиса.

| Русский | English | Различие, которое нужно сохранить |
| --- | --- | --- |
| стратегия | strategy | В простой одновременной игре — действие; в общем случае — полный план |
| исход | outcome | Что произошло; не оценка желательности |
| выигрыш | payoff | Как игрок оценивает исход; не обязательно деньги или оценка |
| строго доминирует | strictly dominates | Строго лучше против каждого действия другого игрока |
| строго доминирующая стратегия | strictly dominant strategy | Доминирует каждую другую собственную стратегию |
| строго доминируемая стратегия | strictly dominated strategy | Другая стратегия строго лучше во всех случаях; именно её не следует выбирать |
| лучший ответ | best response | Условен относительно действия партнёра; может не доминировать |
| дилемма заключённого | prisoner’s dilemma | Сохранять стандартный английский термин |
| Парето-неэффективность | Pareto inefficiency | Возможен переход, улучшающий положение кого-то без ухудшения остальных |
| координация | coordination | Лучшее действие зависит от действия партнёра |

`pareto-efficiency` остаётся историческим ID и адресом понятия. Его заголовок в этой главе — «Парето-неэффективность» / «Pareto inefficiency». Не менять ID ради перевода.
