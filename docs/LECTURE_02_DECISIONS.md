# Лекция 2: решения для дальнейшего авторского процесса

Исторический первичный документ: `references/handoff-lecture-02/docs/LECTURE_02_DECISIONS.md` (принятие RU, 31 октября 2026). В текущем запросе 1 ноября 2026 пользователь прямо подтвердил: “Lecture 1 and Lecture 2 are now approved reference lessons”, дополнительно потребовав изучить утверждённые RU/EN реализации. Принимаем обе главы как эталоны для создания skill. Это не команда на commit/push/deploy и не новая автоматическая отметка одобрения будущего материала.

Не изменяются утверждённые тексты и данные `src/content/chapters/yale-econ-159/lecture-{01,02}/`. Техническая история проверок: [LECTURE_02_QA.md](LECTURE_02_QA.md), [LECTURE_02_EN_REVIEW.md](LECTURE_02_EN_REVIEW.md), [CORE_READING_UX_QA.md](CORE_READING_UX_QA.md).

Переносимые решения:

- Три режима, самостоятельное повествование и полное условие каждой Mastery-задачи; никаких обязательных quiz-gates. Авторские задачи не приписываются Yale.
- Пары выигрышей всегда строка → столбец. Матрица считает обе стороны, отдельно лучшие ответы и доминирование среди чистых стратегий. Равенства сохраняются; C в Yale 2×3 не окрашивается как глобально доминирующая, R доминируема. Слабое и строгое отношения различаются.
- Practice не выдаёт итоговый анализ до явного check, изменение ответа отменяет проверку. Разбор доступен и после ошибки. Реальные API важнее предложений старого handoff.
- Исторические значения и ограничения последовательного исключения указаны явно. Mastery 05 имеет ответы 45/22; это эталон конкретного расчёта, а не универсальная константа автора.
- Прогноз из Лекции 1 переносится через текущий learning store, без использования исторического prototype-key `atlas_v3_number`; исходное, текущее и повторное значения разделены. Без предыдущего ответа можно начать в Лекции 2.
- RU/EN используют общие модели, IDs, ключи и состояние; captions/roles/explanations локализованы. Терминология восстанавливается по оригиналу, не через обратный перевод.
- Сырые исходники и внутренний handoff не публикуются автоматически. Skill создаётся после интеграции библиотеки — это условие текущим запросом выполнено.

Непереносимые особенности: восемь шагов, семь задач, именно эти матрицы, игра 1–100, шляпы и конкретная последовательность понятий. Следующая лекция выбирает собственную образовательную форму.
