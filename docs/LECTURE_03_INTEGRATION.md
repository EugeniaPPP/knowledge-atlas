## Решение для числовых ответов M01

Intent: читатель сравнивает собственные позиции 1 и 2 и вводит число голосов, сохраняя в поле зрения обе альтернативы.

Hierarchy: два коротких контекста «Твоя позиция: 1/2», под каждым подпись единицы «Голоса из 60» и отдельное достаточно крупное поле. Длинная фраза «Мои голоса при выборе…» не конкурирует с числом.

Domain/signature: кандидат, позиция, группа голосов, доля, сравнение. Парные поля соответствуют именно двум сравниваемым стратегиям, а не двум кандидатам. Нейтральный фон, угольный текст, серые подписи, лиловый focus; без дополнительных карточек или цветов.

Surfaces/depth: существующий control-bg и тонкая граница, радиус 3px. Typography: Inter, labels 14px, units 12px, ввод 24px с tabular numbers. Spacing: сетка 4px, две колонки с промежутком 16/24px, поле не ниже 52px. На 320px обе альтернативы остаются рядом. Это opt-in представление AnswerPart; существующие поля главы 2 сохраняются.

## История локального просмотра до публикации

- До приёмки глава имела `reviewOnly: true`, `availableLocales: ["ru", "en"]`; обе локальные редакции были полными.
- `npm run dev` и `npm run build:review` показывали review-главу; обычная сборка скрывала её маршруты и новые понятия.
- После разрешения пользователя `reviewOnly` снят. Сам механизм остаётся для будущих непроверенных глав.
- Математические данные/IDs/ключи общие и готовы к EN; тексты UI лежат в MDX/JSON. Прогресс — стандартный learning store главы, без новых LocalStorage-ключей.

## Состав

Core — семь шагов с постепенным раскрытием и принятым ElectionExplorer; согласованный RU-график сохранён, EN использует те же линии, цвета и границы с английскими подписями. Quick — статический MDX. Mastery — шесть Exercise, 13 AnswerPart, CheckTask, MasteryScore и optional SelfExplanation. Проза и решения RU сохраняются обратимой технической миграцией; источники/редакционные примечания доступны в штатном drawer. Три новых понятия RU/EN видны только вместе с локальной главой.

Двуязычная приёмка и команда публикации получены; будущие изменения текста и последующие публикации требуют соответствующего нового решения пользователя.
